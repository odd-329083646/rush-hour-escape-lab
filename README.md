# Rush Hour Escape Lab

Create a Rush Hour grid puzzle game inspired application with a clean, modern design using React and Tailwind CSS.

Home Screen:

Display a title "Rush Hour - Vanishing Cars Edition".

Show three difficulty selection buttons: "Beginner" (מתחילים), "Advanced" (מתקדמים), and "Champions" (אלופים).

Clicking any difficulty navigates to the Game Screen for that mode.

Game Screen Layout:

Center: A 6x6 grid representing the parking lot.

Right Sidebar: A list/palette of all available cars in the game (different colors, lengths of 2 or 3 cells, vertical or horizontal orientation).

Left Sidebar:

Direction controls (Arrows: Up, Down, Left, Right).

Step count selector (Numbers 1 to 4).

An "Execute" (בצע) button.

Include a "Back to Home" button at the top.
